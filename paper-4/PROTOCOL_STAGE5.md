# Paper 4 — Stage 5: making the positive control informative about the data (frozen before any result)
Committed 2026-10-31, after the fourth ICML-style review (4/10, soundness 3). Objection: the Stage-3 positive control measures how weak the learners are, not how much content heterogeneity the data contain — no well-specified reference learner, one θ/label draw, one injection form, no check that the synthetic panels resemble the real data. Any change after the first result is logged under "Amendments".

## S5-1: a well-specified reference learner (what 20 ratings can reveal at best)
On each synthetic panel (τ0 … τ20), for each test rater, fit θ_r (2-d) by MAP on the rater's k adaptation ratings with the **true injection form**: y ~ softmax(log P̂ + (θ_rᵀg_i)(−2, −1, 0, 1, 2)), g_i the two known features, prior θ_r ~ N(0, σ²I) with σ² estimated by marginal-likelihood-free empirical Bayes on the training raters (σ² chosen from a grid by held-out LL of training raters' half-split adaptation). Two base distributions log P̂: (a) **oracle base** = the generator itself (an upper bound); (b) **estimated base** = D head + DFs offsets fitted on training raters × training items (realistic). Outcome: own − other direction accuracy at k = 20 and 50 (same permutation control, folds, draws, bootstrap as Stage 3). Reported per τ, with the fraction of the generator-oracle gain recovered. The **statistical detection limit** is the smallest τ at which the estimated-base reference learner's own − other lower bound exceeds +1 point at k = 20.

## S5-2: seed variability
Three further synthetic draws (θ seed and label seed 11, 12, 13; same features, same τ calibration procedure, which is re-run per seed) for τ5 and τ10. Learners: reference learner (S5-1), PAL-B on full features, DL (few-shot-tuned). Reported: own − other at k = 20 and 50 for every seed, and mean and range over the four seeds (original + three). The Stage-3 statement "PAL-B on full features detects τ10 at k = 20" is kept only if it holds (lower bound > +1 point) in at least three of the four seeds; otherwise it is weakened.

## S5-3: learner-free comparison of the synthetic panels with the real data
Statistics computed identically on the real panel and every synthetic panel, all raters, all items: (i) agreement in direction between two raters of the same item (non-tie pairs); (ii) Krippendorff's α (ordinal); (iii) the share of an item's rating variance that is between raters within item. Item bootstrap (B = 2,000) on the real data. A synthetic panel is called **inconsistent with the real data, learner-free,** if any of (i)–(iii) lies outside the real data's 95 % interval. Reported; used to qualify which τ the real data could plausibly be.

## S5-4: an aspect-based injection (more realistic structure)
A second injection family in which content preferences act through observable value dimensions: g_i = the item's consensus aspect differences (mean helpfulness, truthfulness and harmlessness level of B over A across the item's annotators, standardised; 3-d), θ_r ~ N(0, τ²I), calibrated as in Stage 3 to generator-oracle gains of +5 and +10 points (one seed). Learners: reference learner (with g_i known), PAL-B (full features), DL. Same outcomes. (The learners do not see the aspect labels; whether text predicts them is part of what is tested.)

## Forbidden statements
Any S5 statement about datasets other than MultiPref; "the real data contain no content heterogeneity".

## Amendments

**Amendment 1 (2026-10-31 13:00, after the S5-1 and S5-3 results; before any run below).** Results so far: (S5-1) with the injection's features known, the reference learner recovers the injected preference from 20 ratings (estimated base, own − other at k = 20: τ2 +1.25 [+0.82, +1.67], τ5 +5.34 [+4.44, +6.26], τ10 +12.7) — the statistical detection limit lies between +1.7 and +5.2 oracle points, an order of magnitude below the published learners'; (S5-3) every synthetic panel, including τ0, is inconsistent with the real data learner-free (rater-pair direction agreement 0.59 at τ0 vs real 0.673 [0.666, 0.680]; Krippendorff α 0.11 vs 0.28): the text-only generator under-represents item-level consensus, so the synthetic labels are noisier than the real ones. Added, in this order:
**(A) S5-5, real-data reference learner on aspect features.** On the real MultiPref labels, the S5-1 estimated-base reference learner with g_ri = the item's leave-rater-out consensus aspect differences (mean helpfulness, truthfulness, harmlessness levels of B over A across the item's other annotators, standardised; 3-d) and θ_r ~ N(0, σ²I), σ² by the S5-1 empirical-Bayes rule; own − other direction accuracy at k = 20, 50 with the Stage-3 permutation control. This uses other annotators' aspect labels of the test items (an aspect oracle, not a deployable model) and asks whether new raters differ, transferably, in how much they follow these value dimensions. The same learner is run on the aspect-injected panels of S5-4 for calibration.
**(B) Generator v2.** Because of S5-3, the positive control is re-generated with item fixed effects: the generator's text head is replaced by per-item logits fitted on all ratings (ridge-shrunk towards the text head), plus DFs offsets, so that item-level consensus is reproduced; τ0, τ5, τ10 re-calibrated as before; S5-3 statistics recomputed (the panel counts as consistent only if (i) and (iii) fall inside the real 95 % intervals at τ0). If consistent, the reference learner, PAL-B (full features) and DL are re-run on these panels and replace the Stage-3 panels in the paper; if not, the inconsistency is reported as a limitation of the positive control.

**Amendment 2 (2026-10-31 14:25, AFTER the S5-5 and generator-v2 results).** (i) Generator v2 is still inconsistent with the real data (τ0: rater-pair direction agreement 0.604 vs real 0.673 [0.666, 0.680]; α 0.133 vs 0.276); per Amendment 1(B) the Stage-3 panels stay in the paper and the inconsistency is reported as a limitation of the positive control (synthetic labels noisier than real ones; real raters agree more than the generator's predictive distribution implies). Added control: the identical learner with the aspect features set to zero (style offsets only; tag `real_none`), same draws and permutation; the aspect part is read as S5-5 minus this control, per rater, rater bootstrap. Exploratory.

**Amendment 3 (2026-10-31 15:00, after the S5-5 paired result).** S5-5, aspect part = aspect run − style-only control, per rater: +0.16 [−0.28, +0.61] (k = 20), −0.16 [−0.60, +0.29] (k = 50). To calibrate this bound, S5-4 is run now for the reference learner first, with strengths changed from +5/+10 to **+2 and +5** generator-oracle points (the real-data bound is near the low end; changed after seeing it, so labelled): injection features = the item's consensus aspect differences over all its annotators (3-d, standardised), θ_r ~ N(0, τ²I) (seed 1), labels drawn with seed 2; the reference learner uses the leave-rater-out consensus as in S5-5 (estimated base, style offsets re-fitted; same permutation); its own − other at k = 20, 50, together with the same style-only control on these panels, gives the detectable aspect part at each strength. PAL-B and DL on these panels follow if time allows.

**Amendment 4 (2026-10-31 16:20, after the fifth review; before any run below).** The review pointed out that own − other is not on the oracle-gain scale: another rater's θ is anti-informative, so own − other roughly doubles the content gain (the reference learner reaches +12.7 at a +10.1-point oracle gain). Added for every reference-learner run (synthetic, seeds, aspect panels, real data): **own − population-content**, i.e. the same rater's fitted style offsets with θ_r = 0, which is on the oracle's scale; it replaces own − other as the reported detection quantity for the reference learner, with the detection criterion unchanged (lower bound > +1 point) and own − other kept. All reference-learner runs are re-done with this output.
