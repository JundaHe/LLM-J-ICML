# Paper 4 — Stage 2c: published personalised reward models (VPL, PAL) under the new-rater protocol (frozen before any result)
Committed 2026-10-28. Motivation: stage 2a/2b compared the factorised style model with a low-rank latent written by us (DL). Reviewers will ask for the published methods. Both are heads on frozen LLM embeddings in their official code, so they are reimplemented faithfully in our pipeline (same folds, raters, k-shot draws, bootstrap as stage 2a) rather than run on their own synthetic benchmarks.

## Methods (from the official repositories, read 2026-10-28)
- **VPL** (Poddar et al., NeurIPS 2024; github.com/WEIRDLabUW/vpl_llm, `hidden_context/vae_utils.py`): each context pair (chosen, rejected) → PairEncoder MLP([e_c; e_r]) → attention pooling over the user's context set → mean / log-variance of z (latent_dim); z = normalised reparameterised sample (mean at test); Decoder MLP([e; z]) → reward; Bradley–Terry loss on (chosen, rejected) + KL to N(0, I). Amortised: a new user's z is computed from their context set with no gradient step.
- **PAL-B** (Chen et al., ICLR 2025; github.com/RamyaLab/pluralistic-alignment, `src/pal_rm_b`): K prototype projectors g_k (MLP) map the prompt embedding to K ideal points; a user's ideal point is Σ_k softmax(w_u)_k g_k(prompt); item projector f maps each response embedding; preference score = −‖f(A) − u‖ + ‖f(B) − u‖ (the `dist` learner); logistic loss. A new user learns only w_u ∈ R^K from their examples (K ∈ {2, 4}, both reported).
Embeddings: Qwen2.5-7B-Instruct last-token hidden states of "prompt + response A", "prompt + response B" and of the prompt alone (new extraction, same model as stage 2a), label-free PCA-256 as in stage 2a. Hyper-parameters: the official defaults where they apply (latent / preference dims, MLP widths, learning rates), otherwise chosen on the stage-2a validation split; listed in the results file.

## Two evaluations
**(E1) Graded, primary for the paper's claim.** Both methods output a scalar preference score s (A over B). To use the 5-level MultiPref labels, s is passed through an ordered-logistic link with 4 learned cut-points, P(y ≤ k) = σ(c_k − s) (the standard graded extension of Bradley–Terry; trained jointly). Compared on held-out LL per rating, RPS and direction accuracy against D, DF and DFs from stage 2a (frozen-feature head) on the same new raters and draws, k ∈ {5, 10, 20, 50}.
**(E2) Binary, the methods' native setting.** Ties dropped, labels binarised (A vs B); VPL and PAL with their native logistic loss; D and DFs evaluated as binary predictors (P(B) = P(B-slightly) + P(B-clearly) renormalised without the tie). Metric: binary accuracy and binary LL on new raters.

## Hypotheses (k = 20, new raters)
- **C1** (E1) DFs − VPL ≥ −0.005 nats (lower bound) and DFs − PAL ≥ −0.005; "better" only if the lower bound > 0.
- **C2** (E2) on binary labels, the advantage of the style model over D vanishes: |DFs − D| binary accuracy within ±0.01 (prediction from stage 2a: DFs is symmetric, so in binary form it can only change calibration).
- **C3** (diagnostic) the per-rater latent of VPL (z, mean) and of PAL (softmax w_u) at k = 50, regressed on the rater's DFs style offsets (3) and DF offsets (5) across raters: R² reported with a rater bootstrap; prediction R² > 0.5 for at least one of the two methods (their user representation mostly encodes response style).
If C1 fails, the paper's claim is restated as "published personalised RMs gain more than three numbers" and the measurement contribution stands alone.

## Amendments
**Amendment 1 (2026-10-28, before any run).** (i) Feature parity: VPL and PAL use per-response embeddings (prompt+A, prompt+B, prompt), whereas stage-2a D/DF/DFs used one embedding of the whole comparison. To compare user models on the same text representation, D, DF and DFs are refitted on the same PCA-256 per-response features (concatenated, 768 inputs) inside stage 2c ("-pair" versions); these are the primary comparators for C1/C2, and the stage-2a numbers are reported for reference. (ii) Hyper-parameters fixed now: VPL latent 512 / hidden 512 / KL weight 0.01 / 8 training contexts (official defaults), Adam lr ∈ {3e-4, 1e-3} and epochs (≤ 20, early stopping) by validation LL; in E1 the pair encoder also receives the one-hot graded label of each context rating (the graded analogue of encoding (chosen, rejected)). PAL-B: d_hid = d_pref = 512, mlp2-gelu projectors, `angle` learner with learnable logit scale (official config), K ∈ {2, 4}; projector lr ∈ {3e-4, 1e-3}, user weights lr 5e-3 (official); a new rater's weights w_u ∈ R^K are fitted on their k ratings by L-BFGS with all else frozen (tiny ridge 1e-3).
**Amendment 2 (2026-10-28, AFTER the first full result — kept as results/stage2c_*_A1.json and stage2c_summary_A1.md and reported).** The first run showed baseline failures that would make C1 an unfair test: (i) **VPL posterior collapse** — the inferred user latents were ≈ 0 for every rater (|z| 0.010, across-rater SD 0.011 per dimension), so VPL ≈ the text-only model (−0.003 nats vs Dp), the failure mode documented for VPL by Kim & Kim (ICLR 2026). (ii) **PAL-B** personalised *worse* than its own text-only use (−0.068 vs Dp) with per-rater weights fitted from k ratings under an almost-zero ridge (10⁻³). Changes, both in favour of the baselines: VPL's KL weight is selected by validation from {0.01 (official), 0.001, 0} (all reported); PAL's adaptation ridge is chosen per k from {10⁻³, 0.1, 1, 10} by k-shot validation on 20 % held-out training raters (PAL refitted without them, the Amendment-5 procedure of stage 2); k = 0 (prior-mean user representation) is added so that every method's own personalisation gain, method(k) − method(0), is reported next to the cross-method contrasts. C1–C3 are re-evaluated on the rerun; both runs are reported.
**Amendment 3 (2026-10-28, before any run of this model).** Hybrid **VPL+s**: VPL (as in Amendment 2, same trained model, z inferred from the new rater's k ratings) plus the three symmetric style offsets of DFs added to its 5 graded log-probabilities (renormalised), the offsets fitted by MAP on the same k ratings with VPL frozen (ridge λ = 2, centred at 0; λ fixed in advance from the values DFsp selected, 0.5–2). E1 only, all folds, k ∈ {5, 10, 20, 50}. Hypothesis **C4**: (VPL+s) − VPL > 0 and (VPL+s) − DFsp ≥ −0.005 at k = 20 (style offsets add to a published personalised RM, and the hybrid keeps VPL's direction accuracy). Reported whichever way it goes.
**Correction note (2026-10-28, from the external review).** The Methods paragraph above describes PAL-B's score with the `dist` learner; the implementation (vpl_pal.py) and Amendment 1 use the official config's `angle` learner (cosine similarity × learnable logit scale). All reported PAL-B results use `angle`.
**Amendment 4 (2026-10-28, after the external-style review; before any PRISM-pair result).** Second dataset for the ranking question, with real users and native pairwise choices. **PRISM pairs:** within each interaction (one user, 2–4 responses to the same prompt, each scored 1–100, one chosen), pair the chosen response with every other response (41,199 pairs, 1,396 users); the A/B side is randomised (seed 0). **Binary label** (native): which response the user chose. **Graded label** (5 levels, thresholds fixed now): d = score(A) − score(B); A≫B if d ≥ 30, A>B if 5 < d < 30, tie if |d| ≤ 5, B>A if −30 < d < −5, B≫A if d ≤ −30. Features: per-response embeddings = the stage-2a PRISM judge-prompt embeddings of (user prompt, response); prompt embedding = new extraction of the user prompt alone (same model). Folds: users (5 folds, stratified by region) × conversations (5 folds); k-shot draws over the user's training-conversation pairs, k ∈ {0, 5, 10, 20}. Models: Dp, DFp, DFsp, VPL, PAL-B (K = 2, 4), VPL+s; the Amendment-2/3 settings. **Primary question (R1):** does any method improve the new user's binary choice accuracy over its own k = 0 version (ranking)? Reported with rater-cluster bootstrap; the ranking-null claim of the paper is stated for PRISM only if every method's improvement at k = 20 has an upper 95 % bound below +0.01. Graded-label results (calibration) reported alongside.

**Amendment 5 (2026-10-28 19:30, after Stage 2 Amendment 9; robustness of the intervals to item sampling, no hypothesis change).** The MultiPref stage-2c runs of the main table (Amendment-2 settings, E1 and E2, all five folds) are repeated with k ∈ {0, 20} and `--dump_ratings`, and the k = 20 contrasts (DFsp − VPL, DFsp − PAL2, DFsp − Dp, VPL − Dp; each method's own gain m(20) − m(0) in LL and in direction / binary accuracy) are re-estimated with the Stage-2 Amendment-9 two-way bootstrap (raters × prompt groups, B = 2,000). Same reproduction rule: the rerun must reproduce the primary point estimates to 1e-3 (training is seeded; the rerun uses the same thread count), otherwise the discrepancy is reported and the rerun is not used. PRISM pairs are not included (prompts are users' own, items nested in users).
